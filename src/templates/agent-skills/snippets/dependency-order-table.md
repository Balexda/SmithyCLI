**Dependency Order table**: columns `| ID | Title | Depends On | Artifact |`, prerequisites first, no checkboxes. `ID` is this level's prefix plus a number, unique, no leading zeros. `Depends On` is `—` (parallel-eligible) or same-table IDs, never prose. Name only real prerequisites (data, contract, or code flow), never an order by convention. `Artifact` is a repo-relative path or `—`; slice rows are always `—`. Ordering rationale goes in advisory notes after the table.
