## Instructions

Answer every question. For plotting questions, write the ordered pair in the form
`(x, y)`. Remember: the **x-coordinate** comes first (left/right), the
**y-coordinate** comes second (up/down).

### Quadrant reference

```
            y
            |
    II      |      I
  (-, +)    |    (+, +)
            |
------------+------------ x
            |
    III     |      IV
  (-, -)    |    (+, -)
            |
```

## Answer Key

| # | Answer | Reasoning |
|---|--------|-----------|
| 1 | Quadrant II | x is negative, y is positive |
| 2 | Quadrant IV | x is positive, y is negative |
| 3 | On the y-axis, 6 units below the origin | A point with x = 0 sits *on* the y-axis; quadrants are the four regions *between* the axes, so points on an axis belong to none of them |
| 4 | `(-3, 5)` | Left 3 makes x = -3; up 5 makes y = 5 |
| 5 | x-coordinate is `-2`; y-coordinate is `9` | The first number is always x |
| 6 | Quadrant III | Both coordinates are negative |
| 7 | False | Order matters. `(3, 5)` is right 3 / up 5, while `(5, 3)` is right 5 / up 3 — two different locations |
| 8 | Move **right 4**, then **down 2** | x = 4 is right; y = -2 is down |
| 9 | `(-7, 0)` | Every point on the x-axis has y = 0 |
| 10 | Quadrant II | (-, +) is the Quadrant II sign pattern |
| 11 | **13 units** | Same y-coordinate, so the length is \|9 − (−4)\| = 13 |
| 12 | Perimeter **26 units**, area **40 square units** | Width = \|6 − (−2)\| = 8, height = \|1 − (−4)\| = 5. P = 2(8 + 5) = 26; A = 8 × 5 = 40 |
