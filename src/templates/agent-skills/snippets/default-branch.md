{{!-- The default-branch lookup D-7 requires: read from the remote, and a forked run that cannot resolve it stops (D-4). --}}
**Read the default branch from the remote** with `git remote show origin` and take `<name>` from its `HEAD branch: <name>` line. The name is remote data that later commands embed: accept it only if it matches `^[A-Za-z0-9._/-]+$` and does not start with `-`, and treat anything else as unresolved. Never assume `main`, and never trust a local `origin/HEAD`, which goes stale when the remote's default changes. If the remote cannot be read or names no single branch, an interactive run asks the user which branch is the default; a forked run with no user to ask stops and reports that the default branch could not be resolved.
